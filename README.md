# 🌴 Sistema de Turismo de Caraguatatuba

## 📖 Descrição

Sistema Web desenvolvido para facilitar o acesso às informações turísticas de **Caraguatatuba**, reunindo em um único lugar informações sobre praias, pontos turísticos, eventos, restaurantes, hotéis e outras atrações da cidade.

## 🎯 Objetivo

Facilitar o planejamento dos turistas, permitindo que eles encontrem informações sobre os principais locais e atrações de Caraguatatuba de forma rápida, organizada e acessível.

## 👥 Público-Alvo

* Turistas que visitam Caraguatatuba;
* Pessoas que estão planejando uma viagem para a cidade;
* Moradores interessados em conhecer os pontos turísticos;
* Profissionais e estabelecimentos do setor turístico.

## ⚙️ Funcionalidades

* 🏖️ Consulta de praias;
* 📍 Consulta de pontos turísticos;
* 🎉 Consulta de eventos;
* 🍽️ Informações sobre restaurantes;
* 🏨 Informações sobre hotéis e hospedagens;
* 🔎 Pesquisa de atrações por categoria;
* 🗺️ Visualização da localização dos pontos turísticos;
* 📷 Visualização de imagens e informações das atrações.

## 📋 Requisitos Funcionais

| Código | Requisito                                                         |
| ------ | ----------------------------------------------------------------- |
| RF01   | O sistema deve permitir consultar pontos turísticos.              |
| RF02   | O sistema deve permitir consultar praias.                         |
| RF03   | O sistema deve permitir visualizar informações sobre as atrações. |
| RF04   | O sistema deve permitir pesquisar atrações por categoria.         |
| RF05   | O sistema deve permitir consultar eventos turísticos.             |
| RF06   | O sistema deve apresentar a localização dos pontos turísticos.    |

## 🛡️ Requisitos Não Funcionais

| Código | Requisito                                                                               |
| ------ | --------------------------------------------------------------------------------------- |
| RNF01  | O sistema deve apresentar bom desempenho durante a navegação.                           |
| RNF02  | O sistema deve proteger os dados dos usuários.                                          |
| RNF03  | O sistema deve possuir uma interface responsiva para celulares, tablets e computadores. |
| RNF04  | O sistema deve possuir uma navegação simples e intuitiva.                               |
